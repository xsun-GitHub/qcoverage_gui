# QCoverage GUI

PyQt6 GUI for calculating and displaying SAXS/WAXS detector q coverage.

Default parameters set for the SAXS WAXS detectors at the P62 beamline at DESY
Can also be used to compare the q range of two detectors or two different settings

support Eiger2 4M, 9M, Perkin Elmer
other detectors maybe added

## Requirements

- Python 3.10 or newer
- PyQt6
- NumPy
- Matplotlib
- pyFAI
